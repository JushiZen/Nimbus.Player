<h2 align="center">すべてのメディアソースを一つのクライアントに</h2>

Nimbus は対応するメディアサーバーと直接接続ストレージを一つの Windows アプリで切り替えるクライアントです。お気に入り、進捗、字幕、バージョン選択は各ソースの機能と権限に従います

メディアファイルは選択した機器やサービスに残り、Nimbus はライブラリをホストせず、映画や番組の配信元を提供しません

---

<h2 align="center">主な機能</h2>

### 統合ライブラリ

- Jellyfin、Emby、Plex、FnVideo に対応
- ローカルフォルダー、SMB、WebDAV、115 Cloud に対応
- 一つのサイドバーから各ソースを切り替え
- ポスターウォール、シンプルリスト、検索、お気に入り、履歴、続きから再生
- 検索、並び替え、ページ取得、お気に入り、進捗の対応範囲は各ソースの API と権限によって異なります

### 直接接続ライブラリの整理

- 通常の映画とシリーズをスキャン・分類し、オンライン識別またはディレクトリの NFO と画像を使用
- ローカル、SMB、WebDAV、115 の各カードで「オンライン取得／ローカル優先・不足分をオンライン補完／ローカルのみ」を個別選択、既定はオンライン取得
- 映画、シリーズ、シーズン、エピソード情報と一般的な Emby／Kodi 命名に対応し、ポスター、背景、サムネイル、ロゴを設定に応じて使用
- ポスター、あらすじ、出演者、エピソード情報を補完
- 詳細画面で手動マッチング、NFO のプレビューとインポート、画像アップロードが可能。解析済み情報と画像コピーを保存し、メディア本体は書き換えません
- 再スキャンでも手動固定とインポートを保持。アップロード元を削除しても保存済みコピーは残り、自動読込のディレクトリ情報削除時は選択方針に従います
- 大規模ライブラリのスキャン、再スキャン、分類、情報保存に対応
- 同じ作品のシーズンをまとめ、重複カードを削減
- TMDB の情報・画像ミラーを個別設定し、空欄で既定に戻せます。JAV と音楽は独立した処理を維持

### 再生

- 独立した再生ウィンドウで、視聴中もライブラリを閲覧可能
- 内蔵字幕と外部字幕、表示位置やサイズの調整
- ハードウェアアクセラレーション、色空間、画質プリセット、ネットワークキャッシュ
- Jellyfin、Emby、Plex の複数バージョンから最高ビットレートを優先可能
- 内蔵 MPV は既定で実際の再生終了まで待って次話に切り替え。正の先行秒数も指定でき、エピソードの長さ以上なら最後まで再生
- 手動選話、先読み、自動・カスタムのオープニング／エンディングスキップを維持し、対応範囲は選択したソースとプレイヤーに従います
- 再生失敗時の診断情報を表示

### アニメとコメント

- アニメ識別とエピソードマッチング
- 複数の一般的なコメントソース
- 速度、サイズ、密度、表示範囲を調整可能
- カスタム色、白／元の色、黒い縁取りを設定可能。メインプレイヤーと FnVideo は個別に対応
- 再生中にコメント内容を検索して切り替え可能

### 音楽

- 音楽ライブラリの閲覧と再生
- 歌詞表示と単語単位のハイライト
- ローカルおよび WebDAV 音声の埋め込みカバーを表示
- 音楽情報は通常の映画・シリーズの NFO／画像方針とは別扱いで、歌詞効果は実際の歌詞ファイルとソースに依存

### 設定と視聴記録

- 設定名と説明をカテゴリ横断で検索し、該当項目を展開・表示
- 巨幕サイドバー、透明表示、ページ／ポスター遷移を設定に応じて使用し、ポスター進入中も戻れます。すべての機器でフレーム落ちがないとは保証しません
- Emby／Plex／Jellyfin の映画とシリーズの並び替え項目はサーバー API に応じて表示
- Trakt を個別認証し、設定に応じて再生報告、進捗、履歴、コレクションを使用。取込範囲はソースと照合に依存し、全ソースの双方向同期は保証しません

<h2 align="center">対応ソース</h2>

### メディアサーバー

**Jellyfin / Emby / Plex / FnVideo**

各サーバーのアドレスとログイン方式で接続し、メタデータ、権限、変換、進捗は各サービスの機能と設定に従います。ディレクトリ方針はサーバー側情報を置き換えません

### 直接接続ストレージ

**ローカルフォルダー / SMB / WebDAV / 115 Cloud**

ファイルの直接閲覧やリソースライブラリの作成が可能です。「ローカル情報」は選択したソースのディレクトリ内の NFO と画像を指すため、SMB、WebDAV、115 には接続が必要です。「ローカルのみ」はそのカードの通常映画・シリーズのオンライン補完を止める設定であり、アプリ全体のオフライン化ではありません

---

<h2 align="center">対応範囲と互換性</h2>

- ISO／ディスクの互換性はファイル構造、メディアソース、プレイヤーによって異なり、構造やネットワークソースによって再生できない場合があります。完全なメニュー操作や暗号化ディスクの復号は保証せず、ISO、BDMV、DVD の認識だけで正常に再生できるとは限りません
- JAV、音楽、各メディアサーバーは独立した処理です。コメント、字幕、変換、歌詞、Trakt には対応する設定、API、情報が必要で、全ソースが同じ機能を持つわけではありません
- 開発中・未公開の項目は利用可能な機能に含めません。画像は表示例であり、配置、テーマ、項目はインストール済みバージョンと設定に従います

<h2 align="center">データとプライバシー</h2>

- Nimbus がメディアファイルをアップロードまたはホストすることはありません
- 接続に必要な設定を保存します。信頼できる機器で使用し、アカウントとアプリデータを適切に管理してください
- ローカル情報、キャッシュ、フィードバックファイルは選択したデータフォルダーを使用し、サーバーの視聴記録や有効な Trakt 同期は対応サービスに送信されます
- オンライン情報、コメント、字幕、更新確認などは対応サービスに接続し、すべての操作がオフラインではありません
- ログでは機密情報をできる限り隠しますが、問題報告前にパスワード、トークン、完全なサーバーアドレス、個人パスを削除してください

[GitHub Issues](https://github.com/JushiZen/Nimbus.Player/issues) には実際のアプリバージョン、Windows 環境、ソース、再現手順、期待する結果と実際の結果を記載してください。再生の問題では内蔵／外部プレイヤーを明記し、必要な画像やエラー文を添付してください

[公式サイトのフィードバック](https://nimbus-player-website.pages.dev/feedback.html?lang=en) と GitHub Issues は別々に記録します。サイトは文章と公開リンクを受け付けるため WEB 番号と記録リンクを保存してください。ファイル添付や議論には GitHub Issues を利用できます
